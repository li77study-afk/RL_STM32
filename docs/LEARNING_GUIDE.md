# 从数组读懂 Q-learning

## 状态、动作和环境

`state = row * 16 + col`，状态 0 为起点，255 为终点。动作 `UP=0, RIGHT=1, DOWN=2, LEFT=3`。`float q[256][4]` 为每个位置、动作存一个预期折扣回报，它不是概率或距离。

`ql_transition()` 不访问 Q 表：正常移动奖励 -1，撞墙或越界留在原地并奖励 -4，进入终点奖励 +30。每回合从起点出发，最多收集 1024 步。

## 探索与利用

`choose_action()` 以 ε 概率随机选动作，否则选最大 Q 值。训练时最高值相同会随机打破平局，避免初始全零总偏向一个方向。

`epsilon_permille` 是千分数：1000=100%，50=5%。前 2000 回合线性衰减，之后保持 5%。评估不探索，不更新 Q 表，也不改变训练随机数状态。

## TD 更新

$$Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right]$$

α=0.20 是学习率；γ=0.95 是折扣因子；`target` 是本次学习目标；`td_error` 是目标与旧估计的差。

例：旧 Q=2，奖励=-1，下个状态最大 Q=10，目标为 -1+0.95×10=8.5，更新后 Q=2+0.2×(8.5-2)=3.3。

到达终点后没有未来奖励，目标只有 +30。1024 步限制属于采样截断：最后一步仍按非终点转移 bootstrap，然后重新开始回合。这里没有把剩余步数纳入状态，学习的是带折扣的到达目标任务。

在调试器展开 `g_agent.last_state / last_action / last_next_state / last_reward / last_old_q / last_target / last_td_error / last_new_q`，可以逐项对照最近一次更新。`g_agent.q` 是完整 Q 表。

## 板上调度与内存

第一回合刻意放慢动作，之后每批 256 次更新，5000 回合后停止训练，屏幕约每 100 ms 刷新。训练总时间包含等待和显示开销，不能直接代表算法算力。

`g_diag.update_cycles` 是最近一次 `ql_train_step()` 的 DWT 周期数，包含选动作、环境转移等；它不是完整统计基准。`render_us` 包含画图、Cache clean 和 SPI 发送。

Q 表与诊断数据位于不可缓存的 DTCM，SWD 可直接读取。帧缓冲位于 AXI SRAM，CPU 写 SPI；刷新时额外执行 Cache clean，方便读取一致的帧缓冲快照。

## 建议逐项做的实验

1. 将 α 从 0.2 改为 0.05，观察学习速度与路径。
2. 改变 ε 衰减，区分“带探索的训练成功率”和“无探索的评估路径”。
3. 将 γ 改为 0.5，检查远处终点对起点 Q 值的影响。
4. 修改撞墙惩罚或每步代价，观察策略变化。
5. 改地图并重新训练，用测试中的 BFS 检查结果。

一次只改一项，保留相同随机种子对照。固定种子用于复现实验，不表示算法知道答案。复位后 Q 表清零，当前版本不把模型写回 Flash。


## 地图初始化函数

应用初始化按下面的顺序执行：

```c
if (!Map_Init(1)) Error_Handler();  // 选择编号 1~100 的地图
ql_init(&g_agent, QL_SEED);         // 清空旧 Q 表与统计，固定随机种子
```

`Map_Init()` 在 `Learning/map_library.c` 中实现：检查编号，随后用 `memcpy` 将 Flash 中的一张 `MapDefinition` 复制到 `g_current_map`。环境函数从 `g_current_map.cells` 读取墙和道路。非法编号返回 0，保留原图。

这里的地图加载与学习器初始化是两个职责：加载环境不会偷偷训练模型，清空学习器也不会改动地图。因此必须按上述顺序组合调用。只需在 `Q_App_Init()` 修改地图编号并重新编译烧录。

`shortest_steps` 是生成器计算的参考值，仅用于测试和 `BEST` 显示。Q-learning 的动作选择和 TD 更新不会读取它。你可以对照 `PATH` 与 `BEST` 判断模型是否已学到最短路线。
